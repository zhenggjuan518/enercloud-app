# EnerCloud H5 项目 PRD

## 1. 文档信息

- 项目名称：EnerCloud BMS H5 监控平台
- 文档版本：v1.0
- 编写日期：2026-06-08
- 当前阶段：前端原型 / 演示版

## 2. 产品背景

EnerCloud H5 项目用于在移动端展示储能电站 BMS 运行状态，帮助运维人员快速查看站点总览、运行指标、单体电芯异常、能量分析和报表信息。当前代码形态以 React + TypeScript + Vite 构建，页面数据主要为前端模拟数据，尚未与真实后端接口联通。

## 3. 产品目标

1. 在手机端提供轻量、直观的储能监控入口。
2. 让运维人员在 30 秒内完成关键状态确认。
3. 支撑站点概览、运行监测、异常定位、趋势分析、报表下载五类核心场景。
4. 建立基础质量门，保证每次提交至少通过静态检查和生产构建。

## 4. 目标用户

- 电站运维人员：高频查看实时状态、定位异常模块。
- 值班管理人员：关注系统健康度、报表汇总和设备风险。
- 项目演示人员：用于向客户或内部团队展示 H5 监控能力。

## 5. 使用场景

1. 运维人员登录后进入站点总览页，确认站点位置、容量、日放电量和系统健康度。
2. 用户进入运行状态页，查看功率、电流、电压和热力图变化。
3. 用户进入 Cell Matrix，快速筛查异常电芯并查看单体详情。
4. 用户进入数据分析页，查看充放电趋势与能量分布。
5. 用户进入报表中心，筛选和下载日报、周报、月报。

## 6. 功能范围

### 6.1 登录

- 提供演示账号登录。
- 支持用户名、密码输入。
- 支持记住我和错误提示。

### 6.2 站点总览

- 展示站点地图卡片。
- 展示总容量、日放电量、系统健康度。
- 展示当日能量流向图。

### 6.3 运行状态

- 展示实时运行状态卡片。
- 展示功率、电流、电压三类核心指标。
- 展示电池模块温度热力图。
- 支持跳转至 Cell Matrix 详情。

### 6.4 Cell Matrix

- 展示电芯矩阵。
- 支持按电压、温度、SOC 三类维度切换。
- 对异常单体进行高亮。
- 点击单体可查看 SOC、SOH、温度、电压详情。

### 6.5 数据分析

- 展示日 / 周 / 月时间范围切换。
- 展示充放电周期趋势图。
- 展示能量分布饼图。

### 6.6 报表中心

- 支持报告搜索。
- 支持 All / Daily / Weekly / Monthly 筛选。
- 支持报告状态展示。
- 对已生成报告提供下载按钮。

## 7. 非功能需求

1. 移动端优先，手机访问时页面需贴近原生 App 的全屏体验。
2. 页面切换和关键数据刷新需平滑，无明显卡顿。
3. 提交代码后必须通过自动化质量门。
4. 构建产物可直接部署到静态站点环境。

## 8. 当前技术范围与约束

1. 当前项目为纯前端实现，数据由页面内部状态模拟。
2. 暂无后端 API、鉴权服务、真实报表导出能力。
3. 暂无单元测试和 E2E 自动化框架。
4. 当前自动化测试以 lint、typecheck、build 作为第一阶段质量门。

## 9. 验收标准

1. 用户可从登录页进入主流程页面。
2. `/overview`、`/status`、`/cell-matrix`、`/analysis`、`/reports` 路由可正常访问。
3. 手机端打开主流程页面时，不应出现影响内容展示的顶部导航遮挡或横向留白。
4. `npm run lint`、`npm run typecheck`、`npm run build` 全部通过。
5. GitHub Actions 可在 push / pull request 时自动执行质量门。

## 10. 后续迭代建议

1. 接入真实 BMS 数据接口和鉴权流程。
2. 增加 Vitest 单元测试覆盖核心组件和状态逻辑。
3. 增加 Playwright 移动端 E2E，用例覆盖登录、路由切换、关键卡片展示。
4. 接入真实报表导出、异常告警和消息通知。
